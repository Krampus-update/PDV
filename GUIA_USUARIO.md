# Guia do Usuário - PDV

Este guia é para uso diário da equipe (caixa, garçom, cozinha e gerente).

## 1. Acessar o sistema
- Abra o navegador e acesse `http://localhost:3000`.
- Faça login com seu usuário.

## 2. Telas principais

### Painel (Caixa)
- **Principal**: selecione produtos para abrir a comanda.
- **Estoque**: cadastra e edita produtos.
- **Comandas**: acompanha comandas abertas/fechadas e faz o fechamento.
- **Clientes**: cadastro e histórico.

### Garçom (Mobile)
- Lista comandas abertas.
- Abre comanda por mesa/balcão.
- Adiciona itens e acompanha status.

### Cozinha (Produção)
- Exibe itens marcados para cozinha.
- Atualize o status para **Em preparo** ou **Pronto**.

### Gerente
- Relatórios de vendas.
- Histórico de eventos.
- Gestão de usuários.
- Resumo do caixa.

## 3. Fluxo padrão de venda
1. **Abrir comanda** (mesa ou balcão).
2. **Adicionar itens**.
3. **Fechar comanda** em Comandas.
4. Selecionar **forma de pagamento** e finalizar.

## 4. Caixa
- **Abrir caixa** antes do início do turno.
- **Fechar caixa** ao final do turno para registrar o saldo final.

## 5. Promoções
- Cadastradas no painel (aba Promoções).
- Aplicadas automaticamente quando a condição é atendida.

## 6. Dicas rápidas
- Use o menu do usuário (canto superior direito) para **Configurações** e **Sair**.
- Em caso de erro, recarregue a página.

## 7. Suporte técnico
Se algo parar de funcionar:
1. Verifique se o servidor está rodando.
2. Abra o Painel e confirme se o status está **Online**.
3. Informe o erro ao suporte.
